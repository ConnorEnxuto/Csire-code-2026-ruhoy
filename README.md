# RayNeo X3 Pro Form & Rep Detection

A real-time exercise tracking system built for the RayNeo X3 Pro smart glasses. The application monitors movement during exercises to automatically detect and count repetitions, track movement phases, and determine whether each repetition meets the expected movement criteria.

Alongside rep detection, the system analyzes exercise form using movement data such as range of motion, positioning, movement speed, acceleration, and consistency between repetitions. This allows it to identify potential issues such as incomplete repetitions, inconsistent movement, or incorrect positioning.

Detected information is processed in real time and presented through the glasses, allowing users to receive feedback directly within their field of view. This eliminates the need to constantly check a phone or external display during a workout and provides a more hands-free way to monitor exercise performance.

The system is designed to support exercise-specific detection, allowing different movements to have their own rep-counting logic and form requirements. This makes it possible to adapt the system to a variety of exercises while maintaining accurate tracking and meaningful feedback.
